# W<sub>pDDT</sub>: A Windowed Partial Difference Distribution Table Framework for Lightweight Differential Cryptanalysis
This repository accompanies our research on making differential cryptanalysis of
SIMON-like lightweight ciphers more practical.

Partial Difference Distribution Tables (pDDTs) are a common building block in differential trail searches, but they become unwieldy as block sizes grow and probability thresholds drop: tables get large while the proportion of useful high-probability differentials shrinks. This project explores a windowed approach to constructing pDDTs that keeps them compact while preserving the differentials that matter most for trail search.
